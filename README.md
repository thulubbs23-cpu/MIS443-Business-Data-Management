# 🎓 MIS443 – Business Data Management

### Quarter 4 • Academic Year 2025–2026

> **Learning to transform business data into meaningful information and insights through database management, SQL, and data analysis.**

---

## 📚 Course Overview

This repository contains my coursework, assignments, practical exercises, and projects completed for **MIS443 – Business Data Management**.

As a **Business Analysis student**, I use this course to develop practical skills in working with business data, relational databases, SQL, and data management.

Throughout the course, I focus on understanding how data can be:

- Structured and organized
- Stored in relational databases
- Retrieved using SQL
- Analyzed to support business questions
- Transformed into useful business information
- Applied to real-world business scenarios

The course helps connect **technical data skills with business analysis and decision-making**.

---

## 🎯 Learning Objectives

By completing this course, I aim to develop the ability to:

- Understand relational database concepts
- Design relational databases using ER diagrams
- Create and manage databases and tables
- Write SQL queries to retrieve business data
- Apply filtering, sorting, grouping, and aggregation
- Use JOIN operations to combine information from multiple tables
- Understand Primary Keys and Foreign Keys
- Import and manage datasets
- Analyze data to answer business questions
- Apply database knowledge to real-world business scenarios
- Document and manage academic projects using GitHub
